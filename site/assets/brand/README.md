# AI January logo files

The AI January identity kit (IO2-v1, Nov 2026): a purple ironwork crown with "AI" in the negative space, and the name set in Bricolage Grotesque Bold. The full usage guide is `AI-January-IO2-Usage.pdf`.

## Which file to use

| File | Use | Smallest size |
| --- | --- | --- |
| `ai-january-master-lockup-color.svg` | Main logo, big places (posters, slides) | 320px wide |
| `ai-january-master-mark-purple.svg` | The crown alone, big | 160px wide |
| `ai-january-compact-lockup-color.svg` | Logo in small places (site header on desktop, share images) | 240px wide |
| `ai-january-compact-mark-purple.svg` | The crown alone, small (site header on phones, next to the name) | 48px wide |
| `favicon.svg`, `favicon.ico`, `favicon-*.png` | Browser tab and home-screen icons | |

`-ink` and `-black` versions are for one-color printing.

## Rules from the kit

- Light backgrounds only: white or paper `#F1EDF3`. There is no dark version.
- Colors: purple `#6A4C8C`, ink `#2A2035`, paper `#F1EDF3` (the same as the site's `--purple`, `--ink` and `--paper`).
- Leave space around it (about one arch of the crown). Don't stretch, rotate, crop or recolor parts of it.
- Below 48px the "AI" stops being readable, so always put the name next to the crown.
